# Design sources

Original exports from Figma. **Not bundled** in the apps; the bundled versions and how they are
produced are listed in `docs/SETUP.md` §4.

* `brands/logo.svg`, `brands/logo_transparent.svg`: raster logo wrapped in SVG (rendered to `logo.png`).
* `brands/wordmark.svg`: vector, bundled as-is.
* `illustrations/technician-{success,failed}.svg`: raster illustration with the status badge, wrapped in SVG.
